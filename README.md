# L-yy-1024 · 牛来-坚持100秒

> 一个用 **spx（积木/方块）游戏引擎** 做的纵深跑酷小游戏：三条车道向你迎面冲来，坚持 100 秒即通关。

## 玩法简介

你操控一头玩家牛，固定在屏幕下方最前方（最近、最大），三条车道的障碍牛从远处（灭点）由远及近向你冲来。速度只增不减，撑满 100 秒即胜利。

- **禁行牛** → 需要**换道**躲开
- **躺卧牛** → 需要**跳跃**越过
- **n字牛** → 需要**滑铲**穿过
- **金牛** → 主动去撞它，+100 分（增益，不是威胁）

每 12–19 秒触发一次随机事件；撞到任意障碍牛或任务失败即结束，按 `R` 重来。

## 操作说明

| 操作 | 按键 |
| --- | --- |
| 跳跃 | `↑` / `W` / `空格` |
| 滑铲 | `↓` / `S` |
| 向左换道 | `←` / `A` |
| 向右换道 | `→` / `D` |
| 重新开始 | `R` |

## 运行 / 导入方式

1. 打开对应的 **spx 云编辑器**（积木游戏编辑器）。
2. 选择「导入项目」，选中仓库根目录的 **`牛来-坚持100秒.xbp`**（即本项目打包文件）。
3. 导入完成后点击运行即可游玩；也可直接在编辑器里修改 `牛来-坚持100秒/` 下的 `.spx` 脚本与 `assets/` 素材进行二次开发。

> 提示：`.xbp` 本质就是 `牛来-坚持100秒/` 工程目录整体打包的压缩文件，二者内容一致；改源码后重新打包即可得到最新的 `.xbp`。

## 技术说明

- **引擎**：spx 积木游戏引擎。逻辑组织为「唯一 `var` 块（全局状态）→ `func` → 事件处理器」；跨精灵通信走 `broadcast` / `onMsg` + 全局变量。
- **伪 3D 透视**：障碍牛的深度用 `scale = 300 / (300 + z)` 表示，`screenX = laneX * scale`、`screenY = 30 - 80 * scale`，灭点固定在画面中央；玩家牛固定 `z = 0`（scale = 1，永远最大且绘制在最上层）。
- **素材约定**：造型图片相对 `assets/` 根目录解析；`.xbp` 为工程目录直接打包的发布包。

## 二次开发

- 想调难度：改 `main.spx` 里的时间/速度曲线与 `Ox.spx` 的生成间隔。
- 想加障碍类型：在 `Ox.spx` 的 `pickCostume` 与碰撞判定里新增分支，并补对应素材到 `assets/sprites/Ox/`。
- 想换美术风格：替换 `assets/backdrops/` 与 `assets/sprites/` 下的 svg/png 即可，索引见各 `index.json`。
